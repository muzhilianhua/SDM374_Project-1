# SDM374 Project 1 report

This is the IEEE report skeleton. Each member writes the section for their own implementation and cites the relevant `sdm` run id beside every reported number or figure.

Build with a LaTeX installation:

```bash
cd report
pdflatex -interaction=nonstopmode main.tex
```

The current baseline evidence and ablation table are generated by `analysis/ablation/build_table.py`.

Suggested four-page budget: half a page for the abstract and introduction, half a page for the
runner (A), half a page for models (B), half a page for the proposal strategy (C), half a page
for replay (D), one page for experiments and results (E), and half a page for discussion and references.
Use the IEEE column width for figures, label each axis with the metric and unit if applicable,
and distinguish replay from real measurements in the caption. Include source run IDs in captions.
