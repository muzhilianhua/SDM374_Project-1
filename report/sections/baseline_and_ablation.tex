\section{Baseline and Ablation Results}
The quadratic-ridge baseline was reproduced through the CLI. Under frozen-v3.2, run \texttt{20261109-222524-evaluate-baseline-v32} obtained a score of 66.4508 and a top-1 regret of 4.5095. Under the separate five-fold protocol, run \texttt{20261109-222557-evaluate-baseline} obtained MAE 6.8275 and top-50 recall 0.46. These values establish the reference rows for later model and optimizer comparisons.

The complete model-by-variant-by-protocol table is generated by \texttt{analysis/ablation/build\_table.py}. Frozen-v3.2 and five-fold rows are kept in separate protocol groups because their splits and ranking metrics differ.
