# 四个代理模型说明（gp-ard / tail5opt / hp_wlearn / blend_xgb_w20x3）

共同前提：目标 `ramping`；训练集 `dataset_same8/train.csv`（2048 行 × 21 维）；OOF 用冻结划分
`sdm374.same8.splits.2x5x3.frozen.v1`（重复交叉验证 **2 repeats × 5 folds = 10 折**；每折 410 条留出预测，
10 折合计 **4096 条预测行 = 2048 个唯一候选 × 2 次重复**，因此有效独立样本是 2048，不是 4096）；
评分为 `sdm374.surrogate.tolerance.v3.2`（低值集合阈值 132.80，δ=0.5）。

**口径约定（全文统一）**：v3.2 的五项分项 `local_order / local_mae / global_order / global_mae /
top1_regret` 一律写“**得分**”（满分 35 / 15 / 15 / 15 / 20，总分 100，**越高越好**）；
RMSE / MAE / R² / top1 regret / bias 一律写“**原始误差**”（**越低越好**）。得分是评分器对排序正确率、
分段误差给出的相对奖励，**不是误差本身**，两者方向可以相反。

**四个模型都在全量 2048 行上 refit 供交付预测；`metrics.json` 里的 OOF 才是泛化指标，
`in_sample` 是插值，不能当泛化。**

## 1. gp-ard（基线）

### ① 数学形式

均值先验为 0 的高斯过程，协方差由三栋"分块 ARD Matérn-5/2"之和加一项全区域交互再加白噪声组成：

```text
k(x, x') = (1 - w)/3 · Σ_{b=1..3} k_M52(x_b, x'_b; ℓ)  +  w · k_M52(x, x'; [ℓ, ℓ, ℓ])  +  σ_n² δ(x, x')
k_M52(r)  = (1 + √5 r + 5/3 r²) · exp(−√5 r),   r = ‖(x−x')/ℓ‖₂,  ℓ = (ℓ_cost,…,ℓ_resilience) 跨三栋共享
```

训练：目标按折内 `loc/scale` 标准化，`normalize_y=False`，`alpha=1e-8`；后验权重
`α = (K + diag(σ_n² + 1e-8))⁻¹ (y − loc)/scale`；预测均值 `loc + scale·kᵀα`。
超参（7 个长度尺度 + 噪声）用 L-BFGS-B 在对数空间最大化边际似然。`w` 固定 0.1。

### ② 相对 gp-ard 改了什么

本模型就是基线本身（相对队友分支是全量 refit）：上界 3.0、单起点、最多 18 次迭代、交互权重固定 0.1、
噪声初始 0.03。

### ③ 指标与 v3.2 分

总分 **83.1496 ± 3.5470**（得分）；五个分项得分见上表；OOF RMSE 5.2311、低尾 RMSE 4.7669、
低值 MAE 3.8787、原始 top1_regret 2.0014、高段 RMSE 11.2774（均为原始误差）；
in_sample 0.0689（插值，不可当泛化）。

### ④ 适用 / 不适用

- 适用：需要**可校准 σ** 的排序、筛选、以及在训练域内的 LCB / EI（cov68≈0.767、cov95≈0.947，
  接近名义 0.68/0.95，是四个模型里区间行为最可信的）。
- 不适用：外推到训练域之外去找 `< 115.765` 的新区域（见⑤）；也不适合当作"我们已经找到更优解"的证据。

### ⑤ 低端行为

沿"低端下降方向"（k=200 局部加权线性梯度投影到单纯形切空间，步长 0.377，倍率 0–4）从 p01969
（预测 115.794）推进到 4×：预测升到 **129.337**，最小值 113.801，单调下降比例仅 0.143。
即：**离开数据支撑区后明显向均值（≈160）收缩，没有外推能力**；4× 末端仍高于 115.765。

### ⑥ 风险与已知缺陷

- 两个长度尺度撞上界（discomfort=3.0、resilience=3.0），这两维实际被"关掉"，模型主要依赖
  cost / carbon / peak / degradation / ramping。
- 单起点 × 18 迭代，优化日志是 `STOP: TOTAL NO. OF ITERATIONS REACHED LIMIT`，不是严格收敛的 MLE。
- 噪声撞下界 0.001，模型接近插值；in_sample 极好（0.069）不代表泛化好。
- 低尾系统性高估：≤q01 的 bias = +3.008（把低值预测得偏高），这是"找不到 <115.765"的直接原因之一。

## 2. tail5opt（低尾专精）

### ① 数学形式

核与 gp-ard 完全相同，但**似然方差改为按样本权重缩放**，并在加权对数边际似然下重新优化超参：

```text
w_i = 5（若 y_i ≤ 132.80），否则 w_i = 1
K_f + diag((σ_n² + α)/w_i)   ← 等价于 Σ_i w_i (y_i − f_i)² 的加权回归
目标标准化用加权均值 / 加权标准差：loc_w = Σw_i y_i / Σw_i，scale_w = sqrt(Σw_i (y_i − loc_w)² / Σw_i)
```

超参 θ = [log ℓ ×7, log σ_n]，3 起点 × 最多 80 次 L-BFGS-B。最终 `w` 仍固定 0.1。

### ② 相对 gp-ard 改了什么（参数级）

| 参数 | gp-ard | tail5opt |
| --- | --- | --- |
| 长度尺度上界 | 3.0 | **6.0** |
| 起点 × 迭代 | 1 × 18 | **3 × 80** |
| 拟合权重 | 全 1 | **低值 103 行权重 5（权重和 2460）** |
| 噪声 σ_n | 0.00100（撞下界） | 0.00122 |
| 目标标准化 | loc 160.452 / scale 15.767 | **加权 loc 154.856 / scale 19.119** |
| 长度尺度 | 0.2745, 0.2363, 1.0974, 3.0*, 0.1754, 0.1798, 3.0* | 0.3139, 0.2743, 1.2270, 6.0*, 0.2042, 0.2079, 6.0* |
| 交互权重 w | 0.10 | 0.10 |

（* 撞上界；顺序为 cost, carbon, peak, discomfort, degradation, ramping, resilience）

### ③ 指标与 v3.2 分

总分 **83.0766 ± 4.7121**（得分）；local_order 得分 27.053（四模型最高）；
**top1_regret 得分 17.483（四模型最低），对应的原始 top1_regret 是 2.6156，即四模型最差**
（gp-ard 2.0014、hp_wlearn / blend 1.6255）；OOF RMSE 5.3320（原始误差，四模型最差）、
低尾 RMSE **4.3382（原始误差，四模型最好，≤q01 n=42）**、低值 MAE 3.8070（原始误差，四模型最好，
实际 ≤132.80）、高段 RMSE 11.3954；in_sample 0.1454。

### ④ 适用 / 不适用

- 适用：目标明确是"在低值区把更好的方案排前面"（低尾 RMSE 最低、低值 MAE 最低），
  可作为低尾筛选的主模型或与 gp-ard 做集成。
- **不能只看好的一面**：它的原始 top1_regret 从 gp-ard 的 2.0014 恶化到 **2.6156（四模型最差）**，
  即"把最优点排到第一位"的能力反而变弱；低尾专精改善的是误差幅度，不是最优点识别。
- 不适用：需要**低方差**结论时（折间 sd 4.7121，四模型最大；逐折配对 5 胜 5 负，
  p=0.917 只作探索性描述，不做等效判断）；也不适合全局精度报告（OOF RMSE 最差）。

### ⑤ 低端行为

p01969 预测 115.774 → 4× 末端 **127.571**，最小值 113.208，单调下降比例 0.286。
比 gp-ard 略"敢于下探"（最小值和末端都更低），但仍然是**向均值收缩**，4× 末端高于 115.765；
不能靠它外推出新低点。

### ⑥ 风险与已知缺陷

- **折间 sd 4.71**：总分对折的划分很敏感，单折分数可从 ~73 到 ~88。
- 加权把预测整体抬高（加权 scale 19.119 > 15.767），高段 RMSE 11.3954 反而略差于基线。
- 低尾仍有 +2.608 的高估偏差，只是比基线的 +3.008 小。
- 长度尺度 discomfort、resilience 撞上界 6.0，两维被压平。

## 3. hp_wlearn（全局精度对照）

### ① 数学形式

核形式同 gp-ard，但**全区域交互权重 w 也作为核超参学习**：

```text
k(x, x') = (1 - w)/3 · Σ_b k_M52(x_b, x'_b; ℓ) + w · k_M52(x, x'; [ℓ,ℓ,ℓ]) + σ_n² δ
θ = [log w, log ℓ ×7, log σ_n]，w 的优化边界 [1e-3, 0.3]（对数空间）
```

普通（非加权）边际似然，4 起点 × 最多 100 次 L-BFGS-B。

### ② 相对 gp-ard 改了什么（参数级）

| 参数 | gp-ard | hp_wlearn |
| --- | --- | --- |
| 长度尺度上界 | 3.0 | **6.0** |
| 起点 × 迭代 | 1 × 18 | **4 × 100** |
| 交互权重 w | 0.10 固定 | **可学习 → 0.04296** |
| 噪声 σ_n | 0.00100 | 0.00346 |
| 长度尺度 | 0.2745, 0.2363, 1.0974, 3.0*, 0.1754, 0.1798, 3.0* | 0.2399, 0.2058, 0.9836, 5.617, 0.1565, 0.1554, 3.745 |

### ③ 指标与 v3.2 分

总分 **82.5547 ± 4.5861**（得分，四模型最低）；OOF RMSE **5.1136**、MAE **3.2880**、R² **0.8948**
（**原始误差**，三项均为四模型最好），高段 RMSE **10.9036** 最好，原始 top1_regret 1.6255（并列最好）；
但低尾 RMSE **5.3066** 最差（原始误差）；in_sample 0.2515。

### ④ 适用 / 不适用

- 适用：全局精度基准、对高 ramping 区间的误差评估、判断其它模型是否"整体偏了"；
  它的学习权重说明交互项其实很弱（w≈0.043），可作为"加法结构足够"的证据。
- 不适用：低值区搜索（低尾 RMSE 5.3066 为四模型最差，低尾 bias +3.380 也最大）。

### ⑤ 低端行为

p01969 预测 115.923 → 4× 末端 **127.061**（四模型里最低的末端），最小值 115.359，
单调下降比例 0.571（最"平滑上升"）。**依然向均值收缩**，且最小值几乎不再下探（>115.765），
外推能力弱。

### ⑥ 风险与已知缺陷

- **低尾最差（5.3066）**：任务说明里提到的 **5.078** 与本包口径不同 —— 本包统一按
  OOF **4096 条预测行（2048 唯一候选 × 2 次重复）**、`实际值 ≤ q01=122.875`（n=42 预测行 = 21 唯一 × 2）
  得到低尾 RMSE 5.3066；`实际值 ≤ q05` 口径为 5.2846。5.078 未能用包内数据复现，故不引用为结论。
  无论哪种口径，它都是四模型里低尾最差。
- 学习到的 w 很小，等价于把交互项几乎关掉；换数据集/重训时 w 可能不稳定。
- cov68 0.734（四模型最低），σ 略偏乐观。

## 4. blend_xgb_w20x3（最高总分混合 / 不可外推参照）

### ① 数学形式（混合公式）

```text
μ(x) = (1 − α) · μ_gp(x) + α · μ_tree(x),   α = 0.15
σ(x) = (1 − α) · σ_gp(x)                     ← 只缩放 GP 的 σ，**没有**树模型的方差项
```

其中 `μ_gp` 是 `hp_ms` 配置的 GP（与 gp-ard 同核，上界 6.0、4 起点×100 迭代、w=0.1 固定），
`μ_tree` 是交付包里的 XGBoost 模型 `xgb_w20x3_full.joblib`（20 特征、3 目标权重、全量训练）。

### ② 相对 gp-ard 改了什么（参数级）

| 参数 | gp-ard | blend_xgb_w20x3 的 GP 分支 |
| --- | --- | --- |
| 长度尺度上界 | 3.0 | 6.0 |
| 起点 × 迭代 | 1 × 18 | 4 × 100 |
| 长度尺度 | 0.2745, 0.2363, 1.0974, 3.0*, 0.1754, 0.1798, 3.0* | 0.2741, 0.2351, 1.0541, 5.901, 0.1746, 0.1770, 6.0* |
| 噪声 σ_n | 0.00100 | 0.00100 |
| 额外分支 | — | **+0.15 × XGBoost（树模型）**，α 在发现折上选出 |

### ③ 指标与 v3.2 分

总分 **83.5477 ± 4.1309**（得分，四模型最高）；`local_mae` **得分 11.924（满分 15，四模型最高）**；
`top1_regret` 得分 18.380（原始 top1_regret 1.6255，并列最好）。但**原始误差**并不占优：
OOF RMSE 5.2642、低尾 RMSE 5.0654、**低值 MAE 4.0793（实际 ≤132.80，四模型最差）**、
高段 RMSE 11.5442（四模型最差）；in_sample 0.3688。

> 关键反差：`local_mae` **得分**最高（11.924），**原始低值 MAE 却最差（4.0793）**。得分是对
> 分段/排序的相对奖励（分段内相对表现好就能拿高分），原始误差是绝对偏差；两者不能混为一谈，
> 也不能用"得分高"推导"误差小"。

### ④ 适用 / 不适用

- 适用：作为**评分口径下的上界参照**——说明"同一批折上，混合能把总分推到 83.5"；可用于离线打分对照。
- 不适用：**任何依赖 σ 的用途（LCB / EI / 置信区间 / 风险控制）**（见⑥；接口层已默认拒绝，
  见第 6 节）；任何外推（树模型在训练域外只能常数外延，见⑤）。

### ⑤ 低端行为

p01969 预测 115.973 → 4× 末端 **128.722**，最小值 114.526，单调下降比例 0.429。
树分支在训练域外退化为分段常数，**整体仍是向均值收缩**，无法可靠外推到 115.765 以下。

### ⑥ 风险与已知缺陷

- **σ 不合法**：`σ = 0.85·σ_gp` 完全忽略树模型方差，也未经校准验证；cov68/cov95 表面接近名义值，
  只是 GP 分支的覆盖率被稀释后的结果。**不能用于 LCB / EI 或任何采集函数**。
  接口层已强制：`predict(..., return_std=True)` 直接抛 `ContractError`；只有显式
  `return_std_heuristic=True` 才返回这个近似 σ，语义标记为 `uncertainty_kind="heuristic"`。
- **α=0.15 是在同一批发现折上选出的**，属于"边选边评"，总分偏乐观。总分仅比 gp-ard 高 **+0.398**
  （逐折 6 胜 4 负），配对 p=0.329 只作探索性描述，**不能据此推断"更好"或"提升≈0"**。
  统一结论：**备用对照，尚无提高过线率或降低低值误差的证据**。
- 树模型对特征尺度/分布敏感，训练域外无外推能力；树与 GP 的分歧随步长增大（4× 时五模型极差
  ≈19.0）。
- 高段 RMSE 11.5442 是四模型最差：混合把高值区拉坏了。
- 原始低值 MAE 4.0793 是四模型最差：低值区实际偏差比三个纯 GP 都大。

## 5. A1 为什么不在这个包里

`A1_linear_trend_gp`（线性趋势 + 残差 GP 的 universal kriging 两阶段近似）**不随包交付**。
原因是它的趋势项 `βᵀx` 在特征空间里没有界：把权重沿某个方向推远，趋势项会线性放大，
模型可以给出远低于训练集的预测（4× 末端 110.389，唯一低于 115.765）。这不是"模型学到了新区域"，
而是**参数假设的外推**——没有任何实测支撑，也无法用 OOF 验证（留出折里根本没有那么低的真值）。
因此 A1 只能用来**生成待实测候选**（告诉你去哪里采样），不能当作"可交付的预测结论"；
把它和三个数据驱动模型混在一个"可直接预测"的包里，会让人误以为 110 这个数是可信预测。
它的实现与产物保留在 `外推方案/趋势与尾部/`，需要做实验设计时再单独引用。

## 6. 环境与入口

- `gp-ard` / `tail5opt` / `hp_wlearn` 推理只用 **numpy + scipy**，不挑 scikit-learn 版本；
  载荷为 `model.npz` + `params.json`，numpy 1.24.x 与 2.x 都可加载（不使用 pickle）。
- `blend_xgb_w20x3` 需要 **scikit-learn 1.6.1 + joblib + xgboost**（joblib 读取 `xgb_w20x3_full.joblib`）。
- 最小安装：`pip install -r requirements.txt`（含 `xgboost>=2.1,<4`，已验证 3.2.0 与 3.4.x）
- 快速上手：`python load_and_predict.py --list`，然后
  `python load_and_predict.py --model gp-ard --weights "w1,...,w21"`。
- **标准差语义（接口层）**：
  - 三个 GP 模型：`predict(x, return_std=True)` 返回 GP 后验 σ，`uncertainty_kind="gp_posterior"`；
  - `blend_xgb_w20x3`：`predict(x, return_std=True)` **抛 `ContractError`**（`(1-α)·σ_gp` 只是启发式近似，
    不构成后验分布，不能用于 LCB / EI / 过线概率 / 风险排序）；诊断只能用
    `predict(x, return_std_heuristic=True)`，此时 `uncertainty_kind="heuristic"`；
  - `return_std=True` 与 `return_std_heuristic=True` 同时给一律报错，不会静默取其中一个；
  - CLI 对 blend 输出 std 时会打印"启发式近似，不可用于 LCB/EI"，JSON 里也带 `uncertainty_kind`。
  - 回归测试：`tests/test_std_contract.py`；自检：`python load_and_predict.py --self-check` 的检查项 F。
- 训练代码入口见 `README.md` 与 `train_four_models.py`；OOF/评分入口见 `run_oof_and_score.py`；
  不重训的评分复算见 `compute_scores.py`（评分器引用仓库根 `evaluation_v3_2/`、
  冻结划分引用仓库根 `frozen_data/SDM374_data_splits_frozen_v1.zip`，包内不复制副本；
  数据集默认读仓库根 `dataset_same8/train.csv`）。
