# 冻结数据与统一分组

[下载冻结数据包](SDM374_data_splits_frozen_v1.zip)。本包只规定数据与分组，不包含评分标准或模型训练目标。

- **数据**：2048 条记录，21 个 W 权重和真实 ramping，以 `candidate_id` 唯一标识。
- **外层**：重复两次五折，共十组。每组约 80% 用于训练、20% 用于测试；每条记录总共测试两次。
- **内层**：每组外层训练数据再分三折，用于选参；不能接触该组外层测试数据。
- **意义**：大家使用完全相同的样本分组，模型成绩才便于比较。分组随机且数量均衡，但未按 ramping 分层。

解压后运行 `python split_api.py` 检查完整性，并使用 `split_manifest.json` 的 ID 清单读取分组。**不能重新随机划分、改写原始数据或修改冻结包。**

协议：`sdm374.same8.splits.2x5x3.frozen.v1`。

ZIP SHA256：`91fbd29f05d64ff2470e8b8a15ade78b7f234b234bf32f03a67fb4ca5d15a09d`。
