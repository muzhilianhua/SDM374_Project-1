# 第1–8周同环境训练数据

训练和最终评估使用相同三栋楼、相同第1–8周输入曲线、相同控制器和初始状态。学生只收到一张训练表，不另提供验证集。第9–12周不参与本版任务。

## train.csv

共2048行，每行是一组21维控制权重及其八周平均ramping，共23列：

| 列 | 含义 |
| --- | --- |
| candidate_id | 权重组合编号，不是输入特征或时间顺序 |
| b1_cost 至 b3_resilience | 三栋楼各七个控制权重，按楼宇分组 |
| ramping | 这组权重在第1–8周的平均真实仿真指标，越小越好 |

每栋楼的七项依次是cost（电费）、carbon（碳排放）、peak（峰值）、discomfort（温度不舒适）、degradation（电池使用与退化）、ramping（负荷变化）、resilience（储能备用）。每项非负，每栋楼七项之和为1。CSV列顺序依次为第一、第二、第三栋楼的七项权重。

每周168小时。令E[t]为三栋楼第t小时的净用电量之和，单周分数为：

```text
R_week = sum(abs(E[t] - E[t-1]) for t in range(1, 168))
最终分数 = (R_week1 + ... + R_week8) / 8
```

E[t]可以为负，表示向电网送电。相邻差值取绝对值。每周独立初始化，设备状态不跨周接续，不计跨周边界项。

2048组权重均来自原随机采样，没有新增人工参考。本版标签由已有16384条逐周记录求均值，已与原始记录核对。表内的周数没有作为模型特征，2048行也不是2048个时间点。

学生可以自行从这张训练表划分内部验证数据，或做交叉验证。训练、离线评估及在线查询针对同一个固定八周目标，不再考查未见周的泛化。

本包不含楼宇逐小时曲线、设备参数、逐周成绩、独立验证表或模拟器。manifest.json记录数据版本、周范围和校验值。
