# v3.2 综合评分

每个外层测试折分别计分，再取十折平均，满分 100。低值区固定为**真实 ramping ≤132.80**，不是每折最低 5%。

| 分项 | 满分 | 计算 |
| --- | ---: | --- |
| 低值区排序 | 35 | `35 × max(0, 2A低 − 1)` |
| 低值区 MAE | 15 | `15 / (1 + MAE低/s)` |
| 全局排序 | 15 | `15 × max(0, 2A全 − 1)` |
| 全局 MAE | 15 | `15 / (1 + MAE全/s)` |
| 第一推荐差距 | 20 | `20 / (1 + 差距/s)` |

`s` 是当前允许训练数据的真实标签标准差（总体标准差，ddof=0），按未裁剪、未加权的训练数据计算。MAE 是预测偏差绝对值的平均数，越小越好。

**容差比较**：两个样本的真实值差距不超过 0.5，就不比较先后。对其余样本对，权重为 `min((真实差距−0.5)/s, 1)`；顺序预测正确记 1，反序记 0，预测打平记 0.5。`A` 是这些分值的加权平均。预测差除以 s 后绝对值不超过 `1e-12` 视为打平。这个排序指标不是 Spearman。

**第一推荐差距**：从完整测试集中挑预测值最低的一条，取它的真实值减去该测试集真实最小值；预测值完全相同时按 candidate_id 升序选择。这里不使用 0.5 容差。

折内无法计算时应停止并报告，不能丢掉该折。折间标准差只说明波动，不参与扣分。MSE、RMSE、召回率、Spearman 和偏差均不进入总分。

直接使用 [评分代码](surrogate_scoring_v3_2.py) 和 [固定配置](EVALUATION_POLICY_V3_2.json)，完整独立发布包见 [评分 ZIP](SDM374_scoring_v3_2.zip)。若重新选参，使用内层三折 v3.2 均分；本次整理未重新选参。

这是已知数据上的内部评估标准，不能直接证明数据集以外新 W 的寻优效果。
